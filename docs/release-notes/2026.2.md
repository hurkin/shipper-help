# Version 2026.2

**Deployment:** March 25, 2026, 17:00–18:00 PDT

ShipperXL Desktop asks you to update when you restart it or first sign in.

## New

- **HAAL**, the user management tool, has moved to
  [secure.hurkin.com/haal](https://secure.hurkin.com/haal) with a complete redesign.
- **The Queue menu** shows how many items are in your queues, and how many are
  urgent: waiting longer than the queue's maximum hours.
- **Shipline changes are applied as soon as they arrive.** The booking is added to
  your booking-changes queue, with a note listing every change and message.
- **Containers with more than one product,** split by weight: you can now include a
  scale ticket for each product in the container contents. This is being tested.

## Removed

- Scheduled jobs no longer support BCC on emails. Existing BCC addresses were moved
  to CC.
- X-Link has been shut down. It was unused.
- The Web Portal has been shut down. It was unused.

## Fixed

- Some bookings had hidden problems that stopped you from seeing booking changes.
- Sales order lines had trouble when work orders were involved in fulfillment or
  assignment.
- Importing customers with the Import tool expected a Code column.
