# Version 2026.4

**Deployment:** ==🟡October 31, 2026, 17:00–17:30 PDT==

## The web app is now in beta

The ShipperXL web app is now officially in beta. Sign in at
[app.shipperxl.com](https://app.shipperxl.com). It works on your live database, so
you can work in either the web app or ShipperXL Desktop.

Most functions are available. Not yet in the web app, and under review: Carrier
Contracts and Bulk Edit Bookings.

### New in the web app

These aren't in ShipperXL Desktop:

- **[Record history](../instructions/record-history.md):** who changed each record
  and its lines, field by field.
- **Inventory screens:** Receive, Return, Process and Ship Inventory, once only in
  ShipperXL Mobile, and Move Inventory by SKU, tag or location.
- **Maps:** inventory balance by location, and SKUs with a location.
- **Auto Work Orders on the agreement:** set up once for every line, instead of on
  each line. See **Auto Work Orders**, below.
- **Queue diagram:** Admin > Queues draws each queue's path and its scheduled jobs.
- **Settings:** owners get **Admin > Settings**, the web version of the desktop's
  options: company, currency, weight unit, logo, email servers and accounting
  defaults. Email settings can be tested before you save. See
  [Settings](../context/settings.md).

### Different rules in the web app

- **A SKU with inventory history can't be deleted.** Deleting it would delete its
  ledger too, which ShipperXL Desktop does without warning. Mark it inactive
  instead.
- **Your own company and its contacts** can be changed only by an owner.
- **Payments:** anyone who can edit a bill can add a payment and set its Posted date.
  Once it is posted, only an owner can change, unpost or delete it, and a payment can
  be deleted only from an unposted bill. ShipperXL Desktop lets anyone who can edit
  the bill change or delete any payment.

## Changed in the web app and ShipperXL Desktop

### Auto Work Orders

Work order templates are now **Auto Work Orders**. Set them up on an agreement, or
on one of its lines, and Shipper creates the work orders on a cargo as soon as a line
is assigned or fulfilled on it. Before, ShipperXL Desktop added a line's templates
to a cargo when the cargo was opened, and they were kept only if it was saved. Now
this happens however the line is assigned, in the web app or ShipperXL Desktop, so
templates already on your agreement lines create work orders after this release. See
[Work Orders](../context/W001.md).

### Web pages in ShipperXL Desktop

The new web app pages will now appear in the desktop in place of many admin and
configuration windows. The user is signed in automatically. 

## ShipperXL Kiosk

Updates when you restart the app. Minor changes let the web app show the scale's
live weight and camera image.

## ShipperXL Desktop

Updates when you restart the app. Besides the changes above, only third-party
components and the logo change in this release.

## Reference data

All databases now get quarterly updates to their countries, regions, sea ports and
SCAC carrier codes.
