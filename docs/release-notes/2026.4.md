# Version 2026.4
**Deployment:** ==🟡 October 31, 2026, 17:00–17:30 PDT 🟡==

The next planned quarterly release, if needed, is Thursday, December 31, 2026,
17:00–18:00 PST.

> ## ShipperXL Web
> The ShipperXL web app is now officially in beta. Sign in at
[app.shipperxl.com](https://app.shipperxl.com). It works on your live database, so you can work in either the web app or ShipperXL Desktop.

#### New Features
- **[Record history](../instructions/record-history.md):** who changed each record
  and its lines, field by field.
- **Inventory screens matching the mobile app:** Receive, Return, Move, Process, Ship Inventory.
- **Maps:** inventory balance by location, and SKUs with coordinates.
- **Auto Work Orders on the agreement:** create work orders templates for the whole agreement, instead of copying line by line, though that's still available too.
- **Queue diagram:** Admin > Queues draws each queue's path with related scheduled jobs.

#### Minor Changes
- **A SKU with inventory history can't be deleted.** Deleting it would delete its
  ledger too, which ShipperXL Desktop does without warning. Mark it inactive
  instead.
- **Your own company and its contacts** can be changed only by an owner.
- **Payments:** anyone who can edit a bill can add a payment and set its Posted date.
  Once it is posted, only an owner can change, unpost or delete it, and a payment can
  be deleted only from an unposted bill. 
- Work order templates are now **Auto Work Orders**. Set them up on an agreement, or
on one of its lines, and Shipper creates the work orders on a cargo as soon as a line
is assigned or fulfilled on it. Before, ShipperXL Desktop added a line's templates
to a cargo when the cargo was opened, and they were kept only if it was saved. Now
this happens however the line is assigned, in the web app or ShipperXL Desktop, so
templates already on your agreement lines create work orders after this release. See
[Work Orders](../context/W001.md).


> ## ShipperXL Kiosk
> Your kiosk will prompt you to update when you restart the app. There were minor changes to let the web app show the scale's live weight and camera image.

> ## ShipperXL Desktop
> Your windows app will prompt you to update when you restart the app. This app contains minimal changes, but includes updated third-party components, a new logo, and for the majority of Configuration windows these are now replaced with pages from the web app.

> ## Reference Data Updates
> All databases now get quarterly updates to their countries, regions, sea ports and
SCAC carrier codes. This will appear sometime in November once we've confirmed a stable release.
