# Version 2026.4

**Deployment:** October 31, 2026, 17:00–17:30 PDT

## The web app is in beta

The ShipperXL web app is now officially in beta. Sign in at
[app.shipperxl.com](https://app.shipperxl.com). It works on your live database, so
you can work in either the web app or ShipperXL Desktop.

Most functions are available, including some new ones such as the inventory screens
and maps. Not yet in the web app:

- **Pro:** Assets, Letters of Credit
- **Enterprise:** Custom Reports, Inspections, Carrier Contracts
- **Under review:** Bulk Edit Bookings

## ShipperXL Kiosk

Updates when you restart the app. Minor changes let the web app show the scale's
live weight and camera image.

## ShipperXL Desktop

Updates when you restart the app. Only third-party components and the logo change in
this release.

## Reference data

All databases now get quarterly updates to their countries, regions, sea ports and
SCAC carrier codes.
