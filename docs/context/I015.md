# Catalogs

A catalog organizes items into sections and subsections, such as for a product
list. Catalogs are kept in ShipperXL Desktop.

## Things to know

- Sections form a tree: each section can sit inside another.
- An item can be in more than one section.
- Section names can be translated.
- Sections are deactivated, not deleted.
