# Work Centers

A work center is a place inside a work zone where work is done, such as one press.
Separate centers let you schedule each one on its own and trace work back to it.

## Things to know

- **Work Zone is required.** Wherever you pick a work center, the list shows only
  centers in the chosen zone, and changing the zone clears a center that isn't in it.
- **External Class** is the class used for accounting. It can set the class on
  invoice lines for work done there.
- A new work center uses the *Standard* calendar. If your database has none, ask an
  administrator to add it.
- **Work Order Text** is printed on the Work Order report for work at this center.
- **Barcode** identifies the center, for when work there is recorded by scanning.
- **Capacity Unit Type** is the unit the center's capacity is measured in, such as
  containers. Capacity planning is usually left blank.
- Work centers are deactivated, not deleted.
