# Inventory

Inventory looks up what is on hand from the mobile app.

## Things to know

- **Scan or type what you know:** a SKU tag, an inventory tag, a location barcode
  or a work order. You can also type a SKU, location or work order number.
- A SKU or location shows its balance in each location, split into raw and
  processed.
- A tag or work order shows its inventory rows, such as what a work order
  received, moved or shipped.
- Totals are the same as in [SKUs and Inventory Balance](I004.md). Only rows
  already saved count. A line still waiting for **DONE** on another device doesn't
  show.
- This feature only looks. It can't change inventory.
