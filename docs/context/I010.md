# Move Inventory

Move Inventory moves inventory from where it is to another location, in bulk.

## Things to know

- **Build the list first, then move it all at once.** Add a tag (it moves whole,
  from wherever it is), a SKU (choose how much raw and processed to take from each
  location it is in), or a location (choose from every SKU there).
- **Everything or nothing.** Every line is checked before anything moves. If one
  fails, nothing moves and the failing lines show why: not enough on hand, location
  not found, or the same from and to location.
- **To Location** applies to every line that doesn't have its own.
- A tag listed twice is added once. A SKU from the same location listed again takes
  the new quantities.
- Each move writes two rows, out of the old location and into the new one a second
  later, both dated now.
- **Every minute matters.** Moves are dated with the current time. If you record a
  move after the product has already left the new location, the balance there goes
  negative in between.
- Tags are faster and safer than SKUs. A barcode scanner works in the tag field.
