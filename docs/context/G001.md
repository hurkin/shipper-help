# Countries

The country list follows the ISO 3166-1 standard and is kept up to date for you,
with quarterly updates.

## Things to know

- **You can only switch a country on or off.** Everything else is maintained
  centrally. Turn on the countries you use so pickers stay short.
- A country decides how its addresses print, through its address style, and the
  phone and postal code formats.
- If a country is missing or wrong, email support@shipperxl.com. Fixes are made
  for everyone, to the standard.
