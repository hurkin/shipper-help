# Attachments

Prints the attachments on a record, with pictures if you choose.

## What's included

- Run from a cargo, SKU, bill, inspection, scale ticket, booking, agreement, company
  or item.
- **Only public attachments.** Private files are never listed.
- A cargo also lists its scale ticket's attachments, and a scale ticket its cargo's.
- A booking also lists the attachments of every cargo on it.
