# Shipment Inventory Cost

Shows the cost of the inventory used on each booking, by container and SKU, to
report to accounting.

## What's included

- Run for one booking, or for all bookings sailing within the dates (the booking's
  planned departure, or else the shipment's). You can limit it to completed
  bookings.
- **Only bookings with a booking record.**
- **If more than 200 bookings match, the report comes out blank.** Narrow the dates.
- Narrowed by work zone. Rows with no work zone appear only when the not-assigned
  choice is included. A separate choice includes rows processed by an external
  processor.

## Things to know

- Cost is the purchase cost of the SKUs deducted, with estimated variable costs from
  the purchase lines' variable costs.
- Quantity is the processed quantity when there is one, otherwise the raw quantity.
- Weights are in your database's weight unit, with tons as short tons (pounds) or
  metric tons (kilograms).
