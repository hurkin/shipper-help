# Inventory by Location

Lists inventory by location and SKU: the balance carried in, and the activity in
the dates you choose.

## What's included

- Only inventory rows with a **location and a date**.
- Rows dated **before** the start make up the opening balance, marked with an
  asterisk. Rows within the dates show as activity. With no start date, everything
  up to the end date is activity.
- **A SKU completed before the start date is left out.**
- **A SKU and location whose quantities round to 0.0 are left out.**
- Only locations owned by the companies chosen.
- A location with no work zone, a SKU with no supplier, or an item with no commodity
  appears only when the not-assigned choice is included for that list.
- Location filter: the short code, or any short code starting with it.

## Things to know

- Weight is the average unit weight of the rows times the quantity, in your
  database's weight unit. Tons are short tons for pounds and metric tons for
  kilograms.
