# Custom Reports

Custom reports are reports built for your company, beyond the standard set. Roles
with this feature see the custom reports published for your database.

## Things to know

- Custom reports can be built with Report Builder from existing Shipper reports or
  from scratch. Access to the report server is arranged through support.
- Custom reports can include custom fields, which standard reports don't show.
- Each custom report has its own rules for what it includes. Ask whoever built it.
