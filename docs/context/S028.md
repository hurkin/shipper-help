# Bulk Edit Bookings

Bulk Edit changes several bookings at once. Use it when a whole vessel changes date,
name or carrier.

## In the web app

1. Open **Processing > Bookings** or **Documentation > Booking Documents** and click
   **Bulk Edit**.
2. Tick the bookings to change, or click a row to tick it. Ticks are kept when you
   switch views or search again, so you can gather bookings from several searches.
3. Click **Edit N Selected**. The dialog is laid out like a booking's General tab.
4. Fill in only the values to change, then click **Save**.
5. Each booking's result is listed: Saved, Partly saved, Failed or Skipped. Bookings
   that weren't saved stay ticked, so you can try them again. Click **Done** to leave
   Bulk Edit.

Bulk Edit needs write permission on bookings.

## In ShipperXL Desktop

1. Search for the bookings you want to change.
2. Tick the ones to update. The toggle button ticks or clears them all.
3. Enter the new values on the right.
4. Click **Save All**.

## Things to know

- **Only the values you fill in are changed.** Blank values are left alone, so this
  tool can't clear a value.
- You can change the carrier, vessel, voyage, planned departure and arrival, cargo
  due, documents due, late cargo due, earliest pickup, earliest receiving and ramp
  due, and add every ticked booking to a queue.
- The web app can also change the IPI, POL, POD and DLV locations, empty pickup and
  return equipment, planned delivery and the loading terminal (when every ticked
  booking loads at the same port), and add a note to each booking.
- In the web app each booking is saved on its own, so one failure doesn't stop the
  rest. A posted booking is skipped unless you're an owner, and ocean details aren't
  set on a booking that isn't by sea.
- Freight rates locked onto a booking from a carrier contract don't change when the
  contract changes. Update those bookings individually.
