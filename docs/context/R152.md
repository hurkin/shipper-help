# SKU Labels (4000T)

Prints SKU barcode labels (Select 4000T labels), as many copies as you ask for.

## What's included

- Run for a SKU, a work order or a cargo.
- From a work order: every SKU in its inventory and in its cargo's inventory.
- From a cargo: every SKU in its inventory.
- Each SKU prints the number of copies you choose, with its SKU barcode.
