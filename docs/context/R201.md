# Location Barcode Tags

Prints a label-printer tag for each location, to stick at the location and scan.

## What's included

- **Active locations only,** for one location or many.
- A location with no work zone appears only when the not-assigned choice is included.
- **A location whose barcode is blank, or the same as its short code, is left out.**
- Location filter: the short code, or any short code starting with it.
- All location owners are included.
