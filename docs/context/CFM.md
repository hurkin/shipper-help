# Custom Forms

Custom forms are screens built for your company and added to ShipperXL Desktop as
plug-ins, such as a fumigation tool that updates many containers at once. In the
web app, [Bulk Edit](B003.md?id=bulk-edit) on the cargo lists does that job.

## Things to know

- A role with this feature sees the custom forms installed for your database in its
  menu. The forms add themselves, so there is nothing to set up
  here.
- Custom forms aren't available in the web app.
- To change or add a custom form, contact support@shipperxl.com.
