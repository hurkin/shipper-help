# Parties

Parties lets mobile app users look up companies and contacts, such as a grower's
phone number in the field.

## Things to know

- It reads the same companies and contacts as
  [Companies and Contacts](G008.md), with their addresses, notes, categories and
  relations.
- With edit rights on this feature, a user can also add and change parties from
  the app. The same rules apply as on the web: only a name is required.
- This feature doesn't open companies and contacts in the web app. That needs
  [Companies and Contacts](G008.md).
