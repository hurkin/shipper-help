# Country Region Taxonomy

The region taxonomy names the kinds of subdivision each country has, such as
*State* in the United States or *Province* in Canada, following ISO 3166-2. It is
maintained in ShipperXL Desktop.

## Things to know

- Choose a country to see and edit its kinds of region.
- **Display Order** sets the order they are listed in.
- Every [region](G005.md) belongs to one of its country's kinds.
- This list is shared with the standard data. If something is wrong, email
  support@shipperxl.com so it can be fixed for everyone.
- After changing it, press F9 in ShipperXL Desktop to reload the cached lists.
