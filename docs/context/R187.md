# Certificate of Origin (China)

Prints the China certificate of origin for a booking, listing every container. It is
a document: create it on the booking first, then print it.

## What's included

- Run for one document. **The document must be on a booking.**
- Signed, shipper, consignee and seller come from the document's fields *SIGNED*,
  *SHIPPER*, *CONSIGNEE* and *SELLER*.
- One row per container on the booking, with its seal, net weight and contents.
