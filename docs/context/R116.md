# Agreement

Prints an agreement (any type) to send to the other party.

## What's included

- Run for one agreement. **Only agreements with lines print.**
- Each line's description adds the SKU's location (its default location's address,
  memo and description), the bookings it is assigned to (with the destination
  code), and the line memo.
- Address blocks add the address's phone number when it has one.

## Signatures

The buyer's and seller's contacts sign the agreement when they have a signature
image:

1. Make a PNG of the signature, about 250 by 75 pixels.
2. On the contact's party record, upload it as an attachment.
3. Make it **public** and tag it with *Signature* (for example, *Signature Image*).

If a contact has more than one, the newest is used.

## Things to know

- On a line ordered in Each, the unit printed is the SKU's raw unit (such as bales).
- The second quantity is the line's estimated value divided by its price, shown
  only when the estimate isn't simply the quantity.
