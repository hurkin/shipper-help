# Inspection Types

Inspection types are the kinds of inspection you record, such as a customer visit,
an inbound quality check or a moisture test. Each type has its own fields.

## Things to know

- **Mnemonic** is a short unique code. **Description** is what people see.
- **Fields** are custom fields that appear on inspections of this type. Add them,
  order them, and mark them required. Fields come from [Custom Fields](G009.md).
- An inspection type can be deleted only while no inspection uses it. Otherwise
  make it inactive.
