# Barcode Inventory

Barcode Inventory finds inventory by tag barcode, part of a barcode, SKU, or a
barcode and SKU together. It is in ShipperXL Desktop.

## Things to know

- To search by barcode alone, enter at least 5 characters.
- Use **%** for any missing part of a barcode. Adding the SKU makes these searches
  faster and more precise.
- Tags that haven't been given a location aren't in inventory yet, so they aren't
  found here.

In the web app, scan a tag on the inventory ledger (from **Inventory > Balance**) to
see its history.
