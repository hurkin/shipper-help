# Return Inventory

Return Inventory brings product back into inventory, such as a tag that was shipped
and came back. It works like Receive Inventory, and every row it writes is noted as
a return.

## Things to know

- **Returns need a work order.** Choose it first.
- **A tag can come back only if its balance is 0.** A tag that still has inventory
  is refused.
- **A SKU** can be returned too, with the quantity you enter.
- **To Location** applies to every line without its own.
- **Everything or nothing.** If any line fails, nothing is returned and the failing
  lines show why.
- Returned rows are dated now and recorded on the work order's cargo, or on the
  work order if it has no cargo.

## In the mobile app

- Use Return for product left over after processing. For example, 50 of 56 bales
  on a tag were used and 6 go back to inventory.
- The return is tied to the tag's last work order.
- A SKU tag also needs the **FROM** location.
- Press **ADD** for each line, then **DONE**. Nothing is saved until you press
  **DONE**.
