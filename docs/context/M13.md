# Locations

Locations lets mobile app users look up locations, and with edit rights, add and
change them.

## Things to know

- The same rules apply as in [Locations](I009.md).
- Print location barcodes from the web or desktop app with
  [Location Barcodes](R122.md), so locations can be scanned on the movement
  screens.
