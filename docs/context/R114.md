# PPQ Form 576 (attachment)

Prints the PPQ 576 attachment for a booking: its containers and their fumigation
treatments. It is a document: create it on the booking first, then print it.

## What's included

- Run for one document. **The document must be on a booking.**
- The declaration, sell-to, shipper and date inspected come from the document's
  fields *DECL*, *SELLTO*, *SHIPPER* and *A03*.
- One row per container on the booking.
- **Treatments** list each distinct pair of fumigated and opened days. A container
  appears there only if it has a fumigated date and an opened date (actual, or else
  planned).

## Things to know

- The opened day printed is one day after the container was opened.
- The bale type prints as *BIG BALES* when the item description contains " BIG ",
  *STANDARD BALES* for packaging type BN, and *DOUBLE COMPRESSED BALES* for BL.
