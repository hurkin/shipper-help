# Units of Measure

Units of measure are everything Shipper counts or prices in: each, container,
bales, pounds, kilograms, tons, and also currencies. Each unit belongs to a unit
class, such as count, weight or currency.

## Things to know

- **Unit Class can't change** after the unit is saved. Conversions only work within
  a class.
- **Conversions:** one of this unit equals a factor of another unit in the same
  class. Weight conversions are how scale weights become pounds, kilograms and
  tons on reports and bills.
- **Codes matter.** Shipper finds some units by their codes: *CTR* (short code) for
  Container, and alternate codes *EA* for Each, *LBR* for pounds, *KGM* for
  kilograms, *STN* for short tons and *TNE* for metric tons. Don't change these
  codes.
- **Items limit units.** An item's selling and purchased unit classes decide which
  units its lines can be priced per.
- **Currencies are units** in the currency class. The default currency for new
  agreements and bills is set by short code, such as *USD*.
- A unit that has been retired still shows on records that use it.
- Units are deactivated, not deleted.
