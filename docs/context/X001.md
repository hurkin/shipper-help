# Number Schemes

Number schemes issue the automatic numbers for new records: agreements, bills,
bookings, cargo, work orders, SKUs and more.

## Output Mask

The mask is the number's pattern. These parts are replaced when a number is issued:

| Part | Becomes |
|---|---|
| `{YYYY}` `{YY}` | Year |
| `{MM}` `{DD}` | Month, day |
| `{HR}` `{MIN}` `{SEC}` | Hour, minute, second |
| `{NN}` … `{NNNNNNNNNN}` | The counter, padded to that many digits |
| `{N}` | The counter, padded to 7 digits |

Anything else is kept as typed. For example, `B{YYYY}{NNNN}` gives B20260001.

## Things to know

- **The counter restarts when the date part changes.** A mask with `{YYYY}` starts
  again at 1 each year. A mask with `{MM}` starts again each month.
- **Dates are UTC.** Near midnight, the date in a number can differ from your local
  date.
- **A number is used up when it is issued,** even if the record is never saved
  successfully. Shipper draws numbers as late as it can to avoid gaps.
- **Last Number** is the last one issued. The next is one more. Change it only to
  skip ahead or restart, and never set it back below numbers already in use.
- **Mnemonic** is how Shipper finds a scheme (for example, the scheme for sales
  orders), so it can't be changed. Schemes can't be added or deleted here.
- Scale ticket numbers are set per scale, in [Scales](B007.md).
