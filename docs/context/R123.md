# Work Order

Prints a work order for the crew: what to do, where, for which order and booking,
and which inventory to use.

## What's included

- Run for one work order.
- **The order line shown** is the first of these that exists: assignments on the
  work order's cargo, fulfillment on its cargo, assignments on the work order
  itself, then fulfillment on the work order. Quantities of 0 are ignored.
- **Inventory to use:**
  - If the work order has tags waiting (inventory rows with no date), those SKUs are
    listed with what is on hand in each location.
  - Otherwise, the SKUs of its order lines are listed, the same way, with what is
    on hand in each location.

## Things to know

- **Specification pictures:** attachments tagged *Specification* on the work item,
  or on the SKUs (and their items) of the tags waiting on the work order, print as
  pictures. They must be public images to show.
- **Work Order Text** on the work zone and work center prints on the work order.
- The barcode lets the work order be scanned at the kiosk and in the mobile app.
- The container type is the work order's, or else its cargo's.
