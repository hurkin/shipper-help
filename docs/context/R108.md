# Inventory Tags (Cardstock)

Prints a cardstock tag for each inventory tag on a cargo.

## What's included

- Run for one cargo.
- One tag per barcode recorded on the cargo's inventory, with its SKU.
- Rows with no barcode print as a single blank-barcode tag per SKU.
