# Work Zones

A work zone is a general area where work happens, such as a valley or a yard.

## Things to know

- **Group costs by area.** A cost list can be limited to a work zone, for when rates
  are the same anywhere in it.
- **Group work by area.** Work orders, cargo grids, the scheduler and inventory
  balances can all be filtered by zone, so each person sees their own area.
- **Give every location a zone**, so inventory reports group by it.
- Agreement line assignments to a booking need a work zone.
- **External Class** is the class used for accounting. Bill and invoice lines take
  the class of the work zone the work happened in.
- **Work Order Text** is printed on the Work Order report for work in this zone.
- Work zones are deactivated, not deleted.
