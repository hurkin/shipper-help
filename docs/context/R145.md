# AES Data Entry

Gathers what you need to file a booking's export information (AES): ports,
destination, carrier, vessel, consignee, tariff number, value and weight.

## What's included

- Run for one booking.
- **The booking must have a sales order or contract line assigned to it.** Otherwise
  the report is blank.
- It prints one record. Details that come from a line (commodity, tariff number,
  processor, consignee) are taken from the first assigned sales line.

## Things to know

- **Consignee:** the ship-to of a letter of credit linked to the booking, else the
  agreement's ship-to; with no ship-to, the buyer (again preferring the letter of
  credit's).
- The value is the estimated and actual value of all the booking's assigned sales
  lines.
- Weight is the booking's total metric tons, in kilograms.
- The tariff number is the product's, or else its commodity's.
- Origin is the processor's address, or else the assignment's work zone.
