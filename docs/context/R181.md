# Price List

Prints one price list with all its lines.

## What's included

- Run for one price list, from its **Reports** button.
- Every line, with the conditions it applies under: SKU, party, Incoterm, ports,
  container class and type, and memo.
- The list's order dates and ship dates. Ship dates are set in ShipperXL Desktop and
  limit when the list applies (see [Price Lists](I006.md)).
