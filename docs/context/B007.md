# Scales

A scale is a truck scale that weighs in pounds or kilograms. Each one has its own
ticket numbering and, if connected, a kiosk, signs and cameras.

## Things to know

- **Unit Type** is the unit the scale reads in, one of the weight units. Weights
  from it are converted from this unit for inventory.
- **Ticket Number Format** and **Last Number** work like
  [number schemes](X001.md), but for this scale's tickets only.
- **Multi Weight** is for short scales that need several weights per truck.
- **Work Zone** is where the scale is. It can decide the work zone used for
  accounting on invoices.
- **The manual scale** holds tickets entered by hand. It is always active and can't
  be deleted.
- Scales are deactivated, not deleted.

## Connecting a kiosk

Only one kiosk can be connected to a scale.

- **Service URL** and **Service MAC** are filled in when the kiosk connects.
- **Service Serial** describes the serial port, separated by colons: port, baud
  rate, parity (None, Even, Mark, Odd, Space), data bits (7, 8), stop bits and flow
  control. For example, `COM24:9600:N:8:1:None`. Use Windows Device Manager to find
  the port.
- **Serial Mask** describes what the scale sends: `?` is any character, `n` a number
  of any length (`nnn` exactly three digits), `*` ignores the rest, and anything else
  must match. For example, `??????? nnnnn KG*` or `n LB`.
- **Sign 1 / Sign 2:** the URL is filled in when a sign connects. The MAC licenses
  the sign.
- **Camera 1 / Camera 2 URL:** a snapshot URL (`http://.../snapshot.cgi`) or an RTSP
  stream (`rtsp://...`).
- **Camera Auth:** for RTSP, `user:password`. For HTTP, `Basic:user:password` or
  `Digest:user:password`.
- **Stack images horizontally** places two camera pictures side by side instead of
  one above the other.
- **PIN** is up to 4 characters.
