# Inventory Transactions

Lists every inventory transaction in a period, newest first: who recorded it, where,
and for which cargo, work order and booking. Useful for checking daily activity,
especially with many users or mobile scanners.

## What's included

- Transactions **dated** within the dates (whole days in your time zone). Run for a
  cargo or booking, it lists all of theirs, whatever the date.
- **Only transactions with a location.** Tags waiting to be received don't appear.
- Narrowed by work zone and location owner. A location with neither appears only
  when the not-assigned choice is included.
- User filter: matches who created or last changed the transaction, exactly.
- SKU filter: an exact SKU match.

## Things to know

- **Origin cargo** is the cargo a tag was first received on, read from the tag's
  barcode. It shows when the transaction is on a different cargo.
- The booking is the work order's, or else the cargo's.
