# Import Data

Import Data loads companies, items, bookings or cargo from a CSV file, in ShipperXL
Desktop. Edit the file in Excel.

## Steps

1. Choose what to import: companies, items, shipments (bookings) or cargo.
2. Download the blank CSV file and fill it in. You can paste in data exported from
   QuickBooks or another system.
3. Choose the file and click **Continue** to review.
4. Read the review carefully. It lists rows that can't be loaded. Fix them and try
   again.
5. Import. Some rows can still fail. Save the failures, fix them and import them
   again.

## Things to know

- **Import never changes existing records,** even when a company or item name
  matches exactly. Existing items must be edited in Shipper.
- The review shows the main record only, not addresses and other details.
- **Shipments:** the shipment number is required and must be unique.
- **Cargo:** the cargo number is required. It can be a ticket number or other
  unique identifier. Consecutive rows with the same cargo number become one cargo
  with several inventory rows.
- A SKU that doesn't exist is created, but isn't linked to a supplier. A location
  that doesn't exist is created too.
- Scale tickets are created in pounds.
- Units must already exist.
- Inventory units are positive to add and negative to remove: "-5" takes out 5,
  "5" adds 5.
- Tab-separated files work as well as comma-separated.
