# Documents

A document is a certificate or form filled in inside Shipper from a
[document type](D002.md), and attached to a booking, shipment, agreement or bill.
Documents are added in ShipperXL Desktop.

## Things to know

- **Fill Fields** gathers values from the record using the document type's SQL. It
  fills each field it has a value for, and can set the document number (usually the
  booking number).
- Fields with a default value start with it. Anything still blank is typed in.
- Documents are system-generated forms. General files belong under
  **Attachments** instead.
- **A record with documents can't be deleted.** Once a document exists for a booking
  or an invoice, delete the document first.
- Print a document from **Reports**.
