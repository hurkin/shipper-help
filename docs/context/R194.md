# Weight Certificate

Prints a weight certificate for a booking, with every container's net and verified
gross weight. It is a document: create it on the booking first, then print it.

## What's included

- Run for one document. **The document must be on a booking.**
- The declaration, sell-to, ship-to, shipper and special wording come from the
  document's fields *DECL*, *SELLTO*, *SHIPTO*, *SHIPPER* and *SPECIAL*.
- One row per container on the booking.

## Things to know

- **Verified gross (VGM)** is the net weight plus the container's own tare (pounds,
  or else kilograms). It is blank for a container with no tare.
- The sold weight is in the sales line's pricing unit when that is a weight unit,
  otherwise metric tons.
- The seller comes from the sales orders and contracts fulfilled on the booking. When
  that seller is also the booking's shipper, the *SHIPPER* field's text is used.
