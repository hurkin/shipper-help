# Regions

Regions are the subdivisions of a country, such as states, provinces or counties,
following ISO 3166-2. They are kept up to date for you, with quarterly updates, and
maintained in ShipperXL Desktop.

## Things to know

- Each region belongs to a country and has a kind (state, province and so on) from
  the country's [region taxonomy](G006.md).
- **ISO code** must be unique within the country.
- A region can be given a **market**.
- Turn off regions you don't use, rather than deleting them.
- Regions narrow port and terminal lists, and can match accounting overrides on an
  item by the seller's region.
- If a region is missing or wrong, email support@shipperxl.com so it can be fixed
  for everyone.
