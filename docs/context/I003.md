# Categories

Categories group items, for example Raw, Processed and Services, which are set up
for you.

## Things to know

- Every item needs a category.
- **Custom fields on a category** appear on every item in it, and on those items'
  SKUs, agreement lines and work orders. For example, give Raw products an expiry
  date. Mark fields required where needed.
- Category names can be translated for users working in other languages.
- Categories are deactivated, not deleted.
