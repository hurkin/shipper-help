# PPQ Form 577 Attachment #3

Prints the container list attached to a PPQ 577 phytosanitary certificate, with
each container's seal, copper plate, fumigation and weights. It is a document:
create it on the booking first, then print it.

## What's included

- Run for one document. **The document must be on a booking.**
- Header boxes come from the document's fields *B03* to *B07* and *B10*.
- One row per container on the booking.

## Things to know

- **Fumigated** is the container's actual fumigation time, or else its planned one.
- **A container with a Tested date is starred,** and the phosphine gas statement is
  printed.
- Weights are each container's scale ticket net, in pounds and metric tons.
- The commodity comes from the items in the container's contents. The port and
  country of export come from the booking's port of loading.
