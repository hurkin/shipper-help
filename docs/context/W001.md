# Work Orders

A work order is one job, such as hauling, pressing, loading or inspecting, done by
a worker on a planned date. It links cargo, inventory and bookings, and its actual
start and finish measure throughput.

## The grid

Work orders are under **Inbound**, **Processing** and **Outbound**, each showing
its own movement type. **Outbound** can also switch to outbound from a supplier. A
new work order starts on that menu's movement type.

- **Planned:** not started, with a planned date in the range or no planned date.
  Sorted by planned date, then by the scheduler's order.
- **Incomplete:** started but not finished.
- **Finished:** finished in the range, latest first.

## Where a work order sits

- **On a cargo,** or **on a booking** when there is no cargo yet. A work order on a
  cargo takes the cargo's booking, so it can't have one of its own.
- **Putting a work order on a cargo moves its line items and dated inventory onto
  the cargo.** After that, its Fulfillment and Inventory tabs show the cargo's,
  read-only, with a link to the cargo.
- **Create Cargo** makes a cargo from a work order that has none and puts the work
  order on it.

## Things to know

- **Work Item Type** is a service item. Choosing it sets the unit to the item's
  purchased unit. If the item is bought only by that unit, the unit is fixed.
- A weight unit (pounds, tons) sets **Quantity** to 0, because the quantity comes
  from the scale.
- **Cost Per Unit** fills from the cost list, using the worker, ports, work zone,
  container type and the actual finish (or start) date. A work order made from an
  Auto Work Order with a cost keeps that cost. See [Cost Lists](I005.md).
- The work order number and its hidden sequence come from number schemes when the
  work order is first saved.
- The movement button opens Receive, Ship or Process Inventory with this work order
  already chosen, depending on its movement type.
- **Clone** makes copies of the plan: item, worker, zone, center, ports, booking,
  quantities, references, memo and order lines. It doesn't copy the cargo, actual
  dates, fulfillment or inventory. Clone needs delete rights.
- A posted work order is read-only.
- On **Fulfillment**, a line's **Agreement** names the agreement's type and number,
  such as *Purchase Order 1234*. Click it to open that line on its agreement.
- Finished work orders with a cost and a worker can be billed with
  [Create Bills](W005.md). A billed work order leaves the Create Bills list. If its
  bill is deleted, it can be billed again.

## Auto Work Orders

An agreement can create its own work orders. Each of its **Auto Work Orders** is a
work order Shipper creates on a cargo as soon as one of the agreement's lines is
assigned or fulfilled on that cargo. Nobody has to remember to add it.

- **Where they are set up:** an agreement's **Auto Work Orders** tab holds the ones
  every line takes. A new line takes them all. On a line's **Auto Work Orders** tab,
  tick or clear each of the agreement's for that line, and add any the line needs
  of its own under **This line only**. Save the line first.
- **What one holds:** the work item, movement type, worker, contact, work zone and
  center, unit, container type, ports, references and, optionally, a cost.
  **Include on bills and invoices** is off unless you tick it.
- **What gets created:** one work order per work item on the cargo. A cargo that
  already has a work order for that item doesn't get another. Anything the Auto
  Work Order leaves blank comes from the line's assignment (zone and center), the
  cargo (movement and container type) or the booking (ports).
- **Quantity** is 0 for a weight unit, because the scale ticket fills it.
  Otherwise it is the lines' quantity in the work order's unit, or 1. Until the
  work order starts, it follows later changes to the lines.
- **Cost:** a cost on the Auto Work Order is locked on every work order made from
  it. Without one, each takes the cost list's when it is created.
- Removing a line, or turning an Auto Work Order off, doesn't delete work orders
  already created.
- Completed cargo gets none.
- You need read on work orders to see Auto Work Orders, and write on the agreement
  and on work orders to add or change them. Removing one needs delete on work
  orders. Turning one on or off for a line is editing the line.

## From a SKU's bill of materials

**Add Work Order** on a saved sales order line with an inventory SKU creates the
work orders to make that SKU, from its [bill of materials](I004.md):

- One work order per level of the bill of materials, each assigned to the line
  with the line's quantity.
- A service component names the level's work order. Otherwise it takes the line's
  item.
- Every other component is a planned input of that work order: its SKU, at the
  line's quantity times the component's. A component with no SKU is left out,
  and Shipper says which.
- With no bill of materials, it creates one work order for the line.
- It needs write access to work orders and read access to SKUs. Save the line
  first.
