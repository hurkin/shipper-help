# Inventory Tags (4000T)

Prints label-printer tags (Select 4000T labels) for the inventory tags on a cargo.

## What's included

- Run for one cargo.
- One label per tag barcode on the cargo, with its SKU.
- **Only rows with a barcode.** Inventory recorded by SKU alone gets no tag.
