# Inventory Adjustment

An inventory adjustment is a single inventory row added by hand to correct a
balance, by tag or by SKU. Adjustments are made in ShipperXL Desktop, from a SKU's
inventory ledger.

## Things to know

- **Positive adds, negative removes.** Enter the quantity that brings the balance
  right, not the new balance.
- **Scanning a tag fills in its SKU, location and current balance,** so you can
  deduct it exactly.
- An adjustment needs a **date and time** and a **location** to count. It defaults
  to now. Date it when the difference actually happened, so the ledger stays in
  order.
- Where you can, correct the cargo or work order the inventory belongs to instead,
  so the correction stays with its load. In the web app, cargo inventory rows can be
  edited on the cargo's **Inventory** tab.
