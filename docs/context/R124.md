# Cargo by Location

Lists cargo still on site, by location, with how many days each has been there.

## What's included

- **Cargo not yet delivered to the carrier, not unloaded and not completed.** Once
  any of those dates is set, the cargo drops off.
- Narrowed by location and movement type. Cargo with no location appears only when
  the not-assigned choice is included.
- Can be run for one booking.

## Things to know

- **Days on site** counts from the cargo's Received time to now.
- The location is the cargo's own location, not where its inventory is.
