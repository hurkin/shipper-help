# Documentation Tasks

Documentation tasks are the documents a record needs: phytosanitary certificates,
bills of lading, bank documents and so on. This is the master list. Tasks are then
assigned to customers, sales orders, letters of credit and bookings, and ticked off
as the documents are done.

## Things to know

- **Description** is required. It can be translated for other languages.
- A task can point at what produces the document:
  - a **Document Type**, for documents filled in inside Shipper (such as generic
    certificates);
  - a **Report Name**, for a Shipper report;
  - **Other Report**, for a report or form from another system.
- **Comments** hold instructions for whoever prepares the document.
- Tasks are deactivated, not deleted.
- Assigning tasks to records and ticking them off is done in ShipperXL Desktop. The
  web app's **Booking Documents** screen isn't available yet.
