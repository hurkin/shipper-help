# Bill of Lading Instructions

Prints the shipper's instructions to the carrier for a booking's bill of lading.
It is a document: create it on the booking first, then print it.

## What's included

- Run for one document. **The document must be on a booking.**
- Forwarder, export references, shipper, consignee, notify parties, particulars and
  instructions come from the document's fields, by mnemonic *A01* to *A08*.
- One row per container on the booking, with its seal and net weight in kilograms
  and metric tons.

## Things to know

- Ports in the United States print as *place, state. USA*. Elsewhere they print
  with the country name.
- Packages print as *Bales* when the sold item's packaging type contains "Bale",
  otherwise *No. of Packages*.
- 40 ft and 20 ft container codes print as 40FT and 20FT.
- The seller code is the short code of the seller on the booking's sales orders.
