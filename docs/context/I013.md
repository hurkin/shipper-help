# Item List Report

Lists items with their category, commodity, packaging, freight class and catalog
section.

## What's included

- Every item, active or not, narrowed by the classes, categories, commodities,
  packaging types, freight classes and catalog sections you choose.
- When a list is narrowed, an item with no value for it appears only if the
  not-assigned choice is included. Services have no packaging type or freight
  class, so narrowing either list drops them unless not-assigned is included.
- **An item in several catalog sections appears once per section.** Items in no
  section show as *Not Assigned*.
