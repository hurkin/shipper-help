# Assets

An asset is equipment or property: a vehicle, a tool, or a piece of land. Assets are
kept in ShipperXL Desktop.

## Things to know

- Each asset has a class (vehicle, tool or land) with its own details.
- **An asset can belong to a company.** On a scale ticket, the **Vehicle** list
  shows the drayman's own vehicles first.
- Agreement lines and work orders can name an asset, but this is rarely used.
- Assets are deactivated, not deleted.
