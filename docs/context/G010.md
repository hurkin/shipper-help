# Locale Translations

Locale translations give a custom field's description, and its drop-down choices,
in other languages, so users working in those languages see them in their own.

## Things to know

- Each row is a language (locale) and the text in that language.
- In ShipperXL Desktop, this opens from a custom field or one of its lookup values.
  In the web app, translations are edited on the custom field itself, in
  **Admin > Custom Fields**.
- A language without a row shows the field's own description.
