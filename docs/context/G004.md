# Address Styles

An address style is how addresses are laid out for a country. Shipper uses it to
build the address blocks printed on invoices, bills and other documents.

## Things to know

- **Each country has one style.** An address prints in the style of its own country.
- A block has up to 4 lines. For each part (name, street lines, city, region, postal
  code, country), choose the line it goes on (1 to 4) and its position on that line,
  0 to 9 from left to right.
- The style can also add punctuation and print the address in capitals.
- **The example** at the bottom shows a sample address in the selected style as you
  change it.
- Changing a style changes how new address blocks print. Blocks already saved on
  bills and invoices keep their text.
