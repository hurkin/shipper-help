# Scale

Scale works with a kiosk scale from the mobile app.

## Things to know

- It lists the scale's **incomplete tickets**: tickets still missing a weight.
  They can be found by party, cargo, work order or search.
- It can send commands to the scale's kiosk, such as printing tags for a cargo.
- A ticket is complete once it has both weights. Weights come from the kiosk. See
  [Using the Kiosk](../instructions/kiosk.md).
- This feature doesn't open scale tickets in the web app. That needs
  [Scale Tickets](B004.md).
