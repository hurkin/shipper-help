# Inventory Transaction Table

Lists inventory transactions as a table you can sort, filter and export to Excel,
with running balances and weights. It opens on its own page under **Reports**.

## What's included

- Transactions with a **location and a date**, within the dates if you give them.
- Narrowed by work zone, location, item, SKU and booking (transactions on the
  booking's cargo or its work orders).
- **Beginning balance:** with a start date, each SKU and location that has
  transactions in the period also gets one row for its balance just before the start,
  if that balance isn't zero.
- Newest first.

## Things to know

- Running totals are per SKU and location, in raw and processed units, pounds and
  kilograms.
