# Scheduled Job Log

Lists every time a scheduled job ran, with its result and the record that
triggered it. In the web app the same log is on **Admin > Scheduled Jobs**.

## What's included

- Job runs within the dates (whole days in your time zone), newest first.
- For one job, or all of them.
- You can show failures only: runs whose result starts with "Fail".

## Things to know

- Each run shows when the event happened and when the job acted on it. A gap between
  the two means the job ran later, for example on the service's next pass.
- Scheduled tasks have no record attached.
