# Location Barcodes

Prints a sheet of location barcodes to post or scan from.

## What's included

- **Active locations only,** of the kinds you tick: raw, WIP, finished or cargo
  locations.
- Only locations owned by the companies chosen.
- A location with no work zone appears only when the not-assigned choice is
  included.
- **A location whose barcode is blank, or the same as its short code, is left
  out.**
- Location filter: the short code, or any short code starting with it.
