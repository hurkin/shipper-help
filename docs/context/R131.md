# Inspection Report

Prints an inspection: its type, inspector, date, the SKUs and containers inspected,
and each field's value.

## What's included

- Run for one inspection, or for a cargo (every inspection that includes it).
- **If a cargo has no inspection,** a blank form for the *Receipt* inspection type
  prints, to fill in by hand.
- Every field of the inspection type prints, in its display order, even when it has
  no value. Drop-down fields list their choices.

## Things to know

- SKUs are the inspection's own SKUs, or else the SKUs in the inventory of the
  containers inspected.
- Containers show their booking number.
- Yes/no fields print as \[X\] or \[ \].
