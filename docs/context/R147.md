# SKU Activity

Shows everything that happened to one SKU, grouped by what kind of activity it was,
with weights.

## What's included

Only inventory rows with a location and a date. Each row is put in one category:

- **Inbound:** cargo that added this SKU (not through a work order).
- **Outbound:** cargo that took this SKU out (net negative).
- **Process:** work orders with no cargo that used raw or produced processed
  product.
- **Net Adjustment:** everything with neither a cargo nor a work order, such as
  moves and manual adjustments, totalled by work zone. Only non-zero totals show.
- **Direct Shipment:** purchase lines for this SKU fulfilled by an **outbound** cargo
  that has been loaded or received, such as product shipped straight from the
  supplier.

## Things to know

- **A starred cargo carried other SKUs too.** Its weight is this SKU's share of the
  scale ticket's net weight, by the inventory's weight.
- Weights use the cargo's scale ticket, or else the work order's. Tons are short tons
  for pound scales and metric tons for kilogram scales.
