# Scheduled Jobs

A scheduled job does something when an event happens: send an email, run a report,
run SQL, export data, send a text, update MailChimp or sync with accounting. Some
jobs run on a schedule instead.

## Events

- **Completed and Posted:** each agreement type, bill type and booking/shipment has
  *Completed* and *Posted* events. They fire when the date is set or changed, not
  when it is cleared.
- **Payment Posted:** for invoices, bills, credit memos and letters of credit. It
  fires when a payment's Posted date is set, not when the payment is entered.
- **Add to Queue:** fires when a record is added to the job's queue. A record moved
  in by **Next Queue** doesn't count.
- **Shipment Document Created.**
- **Scheduled Task:** runs on a schedule (below).

**Events can't be taken back.** Mark a booking complete and the job runs, even if you
clear the date a moment later. Complete it again and the job runs again.

## Settings

- **Priority** (0 is highest) orders jobs that fire together.
- The action decides which settings show: recipients, subject and body for email,
  the report and attachment type for reports, SQL for SQL and exports.
- **Replaceable parameters:** use `@ColumnName` for any column of the record that
  fired the event, such as `@ShipmentId` or `@BillNumber`. Names are
  case-sensitive.
- **Iteration SQL** runs the action once per row it returns. Each column becomes a
  case-sensitive parameter. See
  [Payment Posted](../instructions/payment-posted-job.md) for an example.
- `@ExportURL` is a link to the report or export, public for 30 days. `@GUID` is
  unique to each run.

## Schedules

Once a day at a time, once an hour at a minute, every 2 to 23 hours, or once a month
on a day (31 means the last day). Pick days of the week to limit it. With none picked, it
runs every day. Times are in the job's time zone, or UTC if none is chosen. **Override schedule
and run ASAP** runs the job at the next pass, then clears itself.

## Things to know

- **System jobs** belong to Shipper. You can only switch them on or off.
- The **Logs** tab shows each run and its result. **Recent Logs** shows runs across
  all jobs, and can show failures only.
- Emails no longer support BCC. Use CC.
