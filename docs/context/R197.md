# Fumigation Certificate

Prints a fumigation certificate for a booking's containers. It is a document: create
it on the booking first (document type *Fumigation Certificate*), then print it.

## Things to know

- The document type has fields for the declaration, seller, sold-to, ship-to and
  special information. The declaration starts with standard wording that the
  containers were fumigated with Phostoxin.
- **Fill Fields** takes the seller, sold-to and ship-to from an invoice linked to the
  booking, or else from the booking's shipper and the sales agreement on the booking.
  Anything it can't find is filled with \*\*.
