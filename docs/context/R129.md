# Certificate of Origin

Prints a certificate of origin for a booking, listing every container. It is a
document: create it on the booking first, then print it.

## What's included

- Run for one document. **The document must be on a booking.**
- The declaration, sell-to, shipper and ship date come from the document's fields
  *DECL*, *SELLTO*, *SHIPPER* and *SHIPDATE*.
- One row per container on the booking, with seal, net weight in pounds and metric
  tons, units and description from its contents.
