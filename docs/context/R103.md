# Transloaded Bulk Cargo

Lists the containers on a booking that were loaded from other cargo, such as bulk
product transloaded from railcars into containers.

## What's included

- Run for one booking. The booking must have a booking record.
- **Only containers with contents loaded from another cargo** appear. A container
  loaded straight from inventory is left out.
- One row per contents line, showing the source cargo.
- **A container that fulfills several agreements appears once for each.**

## Things to know

- Container weight is its scale ticket's net, in pounds. The container's tare comes
  from tare pounds, or else tare kilograms.
- The split weight uses the contents line's own scale ticket if it has one,
  otherwise the container's.
- The booking total adds the net weights of every container on the booking that
  has transloaded contents. If those containers were weighed on scales with
  different units, rows repeat once per unit.
