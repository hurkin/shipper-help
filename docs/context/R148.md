# Inventory by Location, Barcode

Shows what each tag holds in each location as of a date, so you can find
individual tags.

## What's included

- Inventory rows with a **location**, dated on or before the end of the chosen day,
  grouped by location, SKU and tag barcode.
- **A SKU completed before the day after that date is left out.**
- **A tag whose quantities round to 0.0 is left out.** Inventory recorded by SKU
  without a tag shows as one row with no barcode.
- Only locations owned by the companies chosen.
- An item with no commodity, or a location with no work zone, appears only when the
  not-assigned choice is included.
