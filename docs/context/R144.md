# Inventory by SKU, Location

Shows what each SKU holds in each location as of a date.

## What's included

- Inventory rows with a **location** and dated on or before the end of the chosen
  day.
- **A SKU completed by then is left out.**
- **A SKU and location whose quantities round to 0.0 are left out.**
- A SKU with no supplier, an item with no commodity, or a location with no work zone
  appears only when the not-assigned choice is included for that list.
- Location filter: the short code, or any short code starting with it. SKU filter:
  an exact match.
- All location owners are included.
