# Receive Inventory

Receive Inventory brings tags and SKUs into a location by scanning, like the mobile
app's Receive screen. It is the quick way to receive tags printed earlier.

## What you can scan

- **A work order or cargo:** lists all its tags not yet received, at their expected
  quantities.
- **A tag:** adds that tag.
- **A SKU:** adds a line for that SKU. This needs a work order.
- **A location:** sets the location.

## Things to know

- **To Location** applies to every line without its own.
- **Everything or nothing.** Every line is checked first. If any line fails, nothing
  is received and the failing lines show why.
- A tag is received only if it is waiting (it has no location or date yet). A tag
  already in inventory with a balance can't be received again.
- Rows are recorded on the work order's cargo, or on the work order if it has no
  cargo.
- Receiving dates every row now. It sets the cargo's **Received** time (and, for
  inbound cargo, **Unloaded**) if they were empty, and starts the work order if it
  hadn't started.

## In the mobile app

- Scan the tags, the location you put the product in, and the quantity received
  on each tag. Press **ADD** for each line, then **DONE**. Nothing is saved until
  you press **DONE**.
- Receiving with SKU tags also needs a work order, so Shipper knows which load
  the product came from.
