# Document Types

A document type is a template for a document filled in inside Shipper, such as a
phytosanitary certificate or a generic certificate. It lists the document's fields
and how **Fill Fields** gathers their values.

## Things to know

- **Applies to:** tick Shipments, Bookings, Agreements and/or Bills to say which
  records can have this kind of document.
- **Fields:** each has a mnemonic, a description and an optional default value. A
  field with a default value starts with it.
- **SQL** is what **Fill Fields** runs. Use `@ShipmentId`, `@BookingId`,
  `@AgreementId` and `@BillId` for the record the document is on. It can return
  either:
  - **one row**, with a column named after each field's mnemonic; or
  - **two columns**, one row per field: the mnemonic, then the value.
- A column (or row) named **DocumentNumber** sets the document's number.
- Mnemonics are matched without regard to case.
- Field descriptions can be translated.
- A document type can be deleted only while no document uses it. Otherwise make it
  inactive.
