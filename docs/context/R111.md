# Generic Certificate

Prints a certificate for a booking, with a declaration, the parties and every
container. It is a document: create it on the booking first, then print it.

## What's included

- Run for one document. **The document must be on a booking.**
- The declaration, sell-to, ship-to, shipper and special wording come from the
  document's fields with mnemonics *DECL*, *SELLTO*, *SHIPTO*, *SHIPPER* and
  *SPECIAL*. Their labels are the fields' descriptions.
- One row per container on the booking, with seal, net weight and units from its
  contents.

## Things to know

- The seller is taken from the sales orders and contracts fulfilled on the
  booking's cargo. When that seller is also the booking's shipper, the *SHIPPER*
  field's text is used instead of the name.
- The sold weight is in the sales line's pricing unit when that is a weight unit,
  otherwise in metric tons.
- Packages print as *Bales* when the sold item's packaging type contains "Bale".
- The description can include the contents description as well as the item.
