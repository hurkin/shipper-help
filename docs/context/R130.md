# Processor Instruction

Tells a processor what to prepare for a booking: the sales lines, quantities, SKUs
and where the product is. Commonly sent when another company processes a booking.

## What's included

- Run for one booking.
- **Sales order and contract lines assigned to the booking.** If none are assigned,
  the lines fulfilled on the booking are used instead.
- Narrowed by processor and work zone. Lines with no processor or work zone appear
  only when the not-assigned choice is included.
- Each processor (or work zone, when there is no processor) gets its own section.
- Booking notes marked for the processor are printed.

## Things to know

- **Party addresses show only if the processor is allowed to see them.** The
  processor's company record decides whether the buyer, seller and ship-to are
  disclosed. With no processor, they are shown.
- The purchase price shown is from purchase lines assigned to the same booking for
  the same SKU (or item, or customer SKU). If prices differ it shows the average.
- The second quantity is the line's estimate, scaled to the assigned quantity.
