# Create Bills

Create Bills makes supplier bills in bulk for a date range, from finished work
orders or from purchase fulfillment. Each row in the grid is one bill that would be
created, with its amount already worked out.

## Using it

1. Choose the source: **Work Orders** or **Fulfillment**.
2. Set **From** and **To**. They default to last week, Monday 00:00 through Sunday
   23:59:59. **To** includes that last second.
3. Choose the split option. It regroups the grid, so each row is always one bill.
4. Select the rows to bill, set the **Bill Date** and the queues, and click
   **Create**.
5. The new bill numbers are listed as links.

## Work Orders

- Includes work orders **finished** in the range that have a worker and a cost, and
  aren't on a bill yet.
- One bill per worker. Lines are one per work zone and item, unless you tick **one
  line per work order**.
- Each work order is linked to its line, so it can never be billed twice. It drops
  out of the list once billed.
- A row is flagged when the same worker also has work orders in the range that are
  already billed. The flag names those bills.

## Fulfillment

- Includes purchase order and contract lines fulfilled in the range (by the cargo's
  load or unload time, or the work order's finish), with an amount.
- Bills are grouped by seller, buyer and currency. **One bill per SKU** is on by
  default.
- Line descriptions read *Work zone: SKU*, and the memo gives the SKU and short
  tons.
- **Already billed is a best guess.** Fulfillment has no link to bills, so a row is
  flagged when a bill line for the same agreement line was created after the record
  was entered and covers its day. Check flagged rows before creating.

## Things to know

- Each bill's memo starts with the date range, such as *9/14/2026 - 9/20/2026*.
- Each line gets its accounting codes as it is created: item number, class and
  expense account, from the line's item and work zone, or else the **Default
  Expense Account** in **Admin > Settings**. See
  [How accounting codes are chosen](../instructions/accounting-integration.md?id=how-accounting-codes-are-chosen).
- Terms follow the bill rules: terms coded *BILL*, the supplier's, your company's,
  or the shortest active terms. Due is the bill date plus the terms' days.
- New bills go into the queues you pick, which start as the bill starting queues.
- To create bills you need write access to bills as well as this feature. Without
  it, you can preview but not create.
- Use the queue's **Set Completed** to complete the new bills.
