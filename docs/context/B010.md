# Container Types

Container types describe what a cargo travels in: a 40 ft container, a flatbed, a
pickup. They come from an industry standard list.

## Things to know

- **Container Class** is required and matters. When the class is a container,
  cargo of this type gets a check-digit test on its container number and shows the
  seal, copper plate and tare fields. A flatbed's class isn't a container, so its
  numbers aren't checked.
- Price and cost lists, carrier contract rates and agreement lines can match on the
  class as well as the type.
- **Short Code** is the standard code. You can change descriptions, but don't
  change what a short code stands for.
- Only a few types are active to start with. Turn on the ones you use. Inactive
  types stay on records that already have them.
- Container types are deactivated, not deleted.
