# Booking Cargo

Lists every container on a booking with its seal, contents, weights and the sales
agreements it ships against. Commonly sent to customers and partners.

## What's included

- Run for one booking. The booking must have a booking record.
- Every cargo on the booking, one row per contents line. A container with no
  contents still appears, without items.
- The agreement numbers and references are every sales order and contract
  fulfilled on the booking or its cargo. The buyer, seller and ship-to addresses
  come from one of them.

## Things to know

- Weights are each container's scale ticket net, with metric and short tons
  rounded per container, so the totals add up the rounded values. See
  [Explanation of Rounding](../instructions/rounding.md).
- If containers were weighed on scales with different units, rows repeat once per
  unit.
- Run it before completing a booking to check that every container is there with
  its weight and inventory.
