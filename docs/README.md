# ShipperXL Help

ShipperXL follows your product from purchase to invoice: agreements, bookings,
cargo, work orders, inventory, and the bills and invoices that settle up.

- **New to Shipper?** Read [How Shipper Works](instructions/how-shipper-works.md),
  then [Getting Started](instructions/getting-started.md). Setting up a new
  database? Start with the
  [Implementation Checklist](instructions/implementation-checklist.md).
- **Looking for steps?** See the [Instructions](instructions/).
- **Installing ShipperXL?** See [ShipperXL Desktop](instructions/install-desktop.md),
  [ShipperXL Mobile](instructions/install-mobile.md),
  [the kiosk](instructions/install-kiosk.md) and
  [the label printer](instructions/label-printer.md). For what to buy, see
  [Hardware and Supplies](instructions/hardware.md).
- **What changed?** See the [Release Notes](release-notes/). What's coming next?
  See the [backlog](https://github.com/orgs/hurkin/projects/1).
- **Forgot your password?** [Reset it here](https://secure.hurkin.com/haal/forgot-password).
  Manage your account at [secure.hurkin.com](https://secure.hurkin.com).
- **Billing?** See [Billing](instructions/billing.md). For pricing, see
  [shipperxl.com](https://shipperxl.com/#signup). Don't have a database yet?
  [Start a free trial](https://secure.hurkin.com/hmc/RequestInstance.aspx?app=SHP).

In the app, the **?** button on each screen opens help for that screen.

For anything else, email support@shipperxl.com.
