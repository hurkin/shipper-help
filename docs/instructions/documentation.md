# Prepare Documentation

Documentation means phytosanitary certificates, bills of lading and any other
certificates that go with a booking. Documents are created in ShipperXL Desktop,
from the booking.

1. Open the booking and go to its **Documents** section.
2. Click **Add Document** and choose the document type.
3. The document number fills in, usually with the booking number.
4. Click **Fill Fields**. Shipper gathers what it can from the booking and fills
   the fields that have no default value.
5. Complete anything left blank and save.
6. Print the document from **Reports**.

## Keeping track of what's needed

**Documentation tasks** list the documents a customer, sales order, letter of
credit or booking needs. Set up the master list in **Admin > Documentation Tasks**.
Each task can name a document type, a Shipper report, or a report from another
system.

## Good to know

- What **Fill Fields** fills is decided by the document type's setup. See
  [Document Types](../context/D002.md).
- Once a document exists for an invoice or a booking, that invoice or booking can't
  be deleted.
