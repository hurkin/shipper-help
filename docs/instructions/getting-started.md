# Getting Started

## Overview

This sample page shows the formatting available on the site.

## Options

| Option   | Default | Description                  |
| -------- | ------- | ---------------------------- |
| `name`   | —       | Display name of the shipment |
| `weight` | `0`     | Weight in kilograms          |

## Example

```json
{
  "name": "Sample shipment",
  "weight": 12.5
}
```
