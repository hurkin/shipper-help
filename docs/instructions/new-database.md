# Set Up a New Database

One way to start with your first database: send support@shipperxl.com a copy of all
the documents for one booking. We will enter as much as we can, so you see your own
data in the system.

## Review each list

Review or update each of these lists before you start entering transactions:

| List | What to set up |
|---|---|
| [Categories](../context/I003.md) | Item codes are sorted into categories such as Raw, Processed and Services. |
| [Commodities](../context/I002.md) | The commodities you work with, if any. Each should have a unique scientific name. Don't enter both "Fumigated Timothy Hay" and "Timothy Hay": both are Timothy Hay, so you need only one. |
| [Container Types](../context/B010.md) | There are over a hundred types of containers, trucks, rail cars and so on. Deactivate the ones you won't use. |
| [Cost Lists](../context/I005.md) | What you pay for items. Trucking fees and other costs can be given a cost automatically. Email us for help the first time, to be sure you start right. |
| [Document Types](../context/D002.md) | The documents attached to each shipment. Most are variants of a packing list. If you need more, contact us. |
| [Items](../context/I001.md) | **Very important.** Codes for every product and service you buy or sell. Import them with [Import Data](../context/G012.md), or enter them one by one. |
| [Locations](../context/I009.md) | Every storage location, whether you store containers or product. |
| [Markets](../context/G011.md) | If you buy or sell at different rates to different groups, use markets to separate them. Price and cost lists use them, so owner-operators can get one rate and company drivers another, or customers in Japan one rate and customers in Korea another. |
| [Number Schemes](../context/X001.md) | How invoices, purchase and sales orders and so on are numbered. Easy to change later. |
| [Companies and Contacts](../context/G008.md) | Everyone you do business with, buying or selling. Export them from QuickBooks or Outlook and bring them in with [Import Data](../context/G012.md). |
| [Price Lists](../context/I006.md) | What you sell items for. |
| [Scales](../context/B007.md) | Every scale you issue scale ticket numbers for. The one named *Other* is special: it doesn't need a unique ticket number. |
| [Terms](../context/A007.md) | Net 30, Due on Receipt and so on. Set them up right from the start, and match your accounting system if you can. |
| [Work Centers](../context/W003.md) | Machines or centers of activity you want to track, such as a hay press. Not required. |
| [Work Zones](../context/W002.md) | Areas or sites of operation, so inventory and other information can be separated. A simple, one-site business needs just one. |

With any new database, [contact us](mailto:support@shipperxl.com) for help, or at
least a review of your configuration.
