# Create Custom Reports

There are several ways to report on your own data. Some need advanced skills.

## Power BI: analysis, not real-time

- Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/), or use the
  [Power BI service](https://app.powerbi.com) with a Microsoft 365 subscription.
- The service lets you share reports, build dashboards and mobile views, and
  refresh data on a schedule.

## Report Builder: operational, real-time

- Build reports based on those already in Shipper, or from scratch.
- Connect to the report server with credentials from support@shipperxl.com. This
  access costs extra.
- Published custom reports appear in Shipper for roles that have the Custom
  Reports feature.

## Direct database access

Excel, Access, SQL Server Management Studio and similar tools can connect to your
database with credentials from support@shipperxl.com. This is available only on
Enterprise subscriptions.
