# Implementation Checklist

There is a lot to set up when you start with ShipperXL. Work through this list.

1. Buy [hardware and supplies](hardware.md): label printer, labels, scanners,
   kiosk and so on.
2. If you are setting up a [kiosk](install-kiosk.md), email
   support@shipperxl.com for advice on camera and scale integration.
3. Read [Set Up a New Database](new-database.md) for what to configure first.
4. Set up [user accounts](user-accounts.md) and roles. Give more access at the
   start, then restrict and refine it as you need to.
5. Install [ShipperXL Desktop](install-desktop.md) and
   [ShipperXL Mobile](install-mobile.md) for your users.
6. Set up [email](email-attachments.md), and your
   [accounting integration](accounting-integration.md).
7. Email support@shipperxl.com to make a training plan. We suggest one or two
   sessions a week for up to a month, covering four key sessions:
   - Introduction, purchasing, shipments and sales
   - Inbound cargo, inventory and scale operations
   - Work orders, processing and outbound cargo
   - Bills, documentation and invoices
8. Read the [instructions](./).
9. Decide on a cut-over plan from your existing processes and systems:
   - Choose a date to copy your existing inventory into ShipperXL. For example,
     Jan 31 23:59: everything from Feb 1 on is in ShipperXL.
   - Run both systems side by side for a short time, probably a month or two.
   - Complete a month-end inventory cycle.
   - Turn off the systems and processes you no longer use.
