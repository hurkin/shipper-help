# Label Printer Setup

Tags and labels print on a Zebra desktop thermal transfer printer with Z-Select
4000T 2.25" x 4" barcode labels. See [Hardware and Supplies](hardware.md) for what
to order.

Set the printer's preferences, and its default preferences, as shown below. These
are for a Zebra TLP 2824 Plus.

![[label-printer-settings.png|300]]

On a kiosk, the label printer must be named **labels**.
